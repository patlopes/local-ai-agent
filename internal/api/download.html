Quick Start

1. Download the binary for your platform

2. Make it executable (Linux/macOS):

chmod +x local-ai-agent-*
./local-ai-agent-*

3. Open http://localhost:3333 in your browser

On first run, it will automatically download Ollama and a default model. If you have an NVIDIA GPU, it will use CUDA acceleration automatically.
